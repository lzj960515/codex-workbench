# 思维导图：围绕中心问题建立层级

用于主题发散、分类、学习笔记和需求整理。思维导图让读者从中心到细节理解概念归属；实际先后、条件和状态转换交给对应流程页。

## 内容组织

一个中心主题概括整张图，一级分支覆盖读者理解主题所需的方面。同一层保持相同分类角度，例如全部表达能力、角色、阶段或风险；按某种角度细分时在父节点写清角度。

先提炼材料，再根据读者问题组合。文章目录、会议发言顺序和代码目录都可以提供线索，最后的层级由概念关系决定。代码位置作为证据或叶节点，结论、假设和待确认事项保留各自状态。

节点用短语表达一个概念。一级分支通常为短名称，子主题从概念逐层到细节；重要限制和理由用相邻备注或关联页面承载，详细证据链接回来源。需要解释运行路径时建立独立流程页，并从主题节点提供入口。

一级分支常见为 4—7 个，深度常见为 3—5 层；这些数值是排版参考。以读者能否快速找到主要方面、理解父子关系来决定折叠、拆页或继续展开。缺少来源时明确交付可填写模板，用问题与占位主题表示待补材料。

## 布局与线条

| 布局 | 适用问题 | 阅读方式 |
| --- | --- | --- |
| `both` | 主题总览、发散、能力地图 | 中心向左右展开，按完整子树高度平衡两侧 |
| `right` | README、学习路径、逐层讲解 | 从左侧中心向右读 |
| `left` | 为右侧说明留空间 | 从右侧中心向左读 |

一级分支可以指定侧向，完整子树留在同一侧。兄弟节点保留垂直间距，子树之间留出更大段落间距。颜色表示一级分支归属，后代沿用同色线条和较浅填充。

层级分支采用无箭头曲线，父节点外侧连接到子节点内侧。根、一级分支与细节的视觉重量逐级降低。少量跨分支因果或依赖可用带标签的虚线箭头表示；关系线开始妨碍层级阅读时，转到独立关系图。样式与模板统一见[制作与工具](drawio-authoring.md)。

## 用大纲创建初稿

`$DIAGRAM_SKILL_DIR` 表示当前包实际目录。在目标项目的 `tmp/` 放一次性 JSON 大纲，例如：

```json
{
  "title": "读书笔记",
  "layout": "both",
  "branches": [
    {
      "text": "主要观点",
      "color": "blue",
      "children": [{"text": "作者结论"}, {"text": "支撑证据"}]
    },
    {
      "text": "我的思考",
      "children": [{"text": "适用场景"}, {"text": "待验证问题"}]
    }
  ]
}
```

```bash
python3 "$DIAGRAM_SKILL_DIR/scripts/create_mindmap.py" \
  path/to/outline.json path/to/topic.drawio
```

`layout` 支持 `both`、`right`、`left`，命令行 `--layout` 可覆盖大纲布局。一级分支可用 `side` 指定 `left` 或 `right`，用 `color` 选择 `blue`、`yellow`、`green`、`red`、`violet`、`orange`；子主题沿用分支色。`--page-name` 指定页名。

脚本输出原生、未压缩、可单独编辑的节点与连线。自动排版是初稿，继续根据内容调整位置、顺序、宽度和颜色。制作完成后以 `.drawio` 为权威版本；重新运行生成器前核对手工编辑，局部修改直接编辑当前源图。

## 读取与修改

```bash
python3 "$DIAGRAM_SKILL_DIR/scripts/inspect_mindmap.py" \
  path/to/topic.drawio --format markdown

python3 "$DIAGRAM_SKILL_DIR/scripts/inspect_mindmap.py" \
  path/to/topic.png --format json
```

读取器恢复中心主题、分支层级及跨分支连接。解释时按中心问题、一级分支、关键子主题和关系组织，证据仍待确认的含义单独说明。PNG 源图恢复使用共同检查器，见[制作与工具](drawio-authoring.md#读取与恢复)。

修改时先了解完整层级，再改受影响分支。新增概念归入最贴近的稳定主题，分类变化移动整棵子树；删除节点前安排其子主题归属。优先使用原有空白，必要时只重排受影响子树，保留其他页面、ID 和手工位置。

同级主题的连接顺序和视觉顺序共同表达阅读顺序。插入或移动节点时同步核对 XML 中层级边顺序、父子关系和坐标。

## 验收

先确认中心问题、同级分类、概念覆盖和依据，再检查根到叶节点的连续路径、层级关系、重复概念和跨分支连接。实际查看对应交付结果，确认中心与一级分支容易扫读，颜色和视觉重量稳定，文字及曲线留有空间。

只交源文件时，使用读取器做结构检查，并在原生界面查看。交付 PNG 时，导出、实际查看后运行：

```bash
python3 "$DIAGRAM_SKILL_DIR/scripts/validate_mindmap.py" \
  path/to/topic.drawio path/to/topic.png
```

该命令逐页校验单一中心、可恢复层级、PNG 嵌入信息及源图字节同步，适用于每页都是单中心脑图的文件。目录、流程和脑图放在同一多页文件时，按脑图读取器的逐页输出核对脑图层级，其他页使用各自结构规则；再用通用检查器提取 PNG 源图并对照权威文件。结构错误按输出修正；业务含义与可读性继续由来源核对和实际显示检查证明。
