# Skill 封装与工具

本页用于已经按主流程明确目标，需要创建、修改、合并或校验 Skill 包的工作。以下命令中的 `<writing-for-ai>` 指本 Skill 的实际目录。

## 确定能力与边界

用一句话表达 Skill 的稳定职责，结合真实请求检查它是否提供独立有用的能力，或应融入已有 Skill。判断型任务明确需要改善的选择、依据和停止结果；操作型任务明确权限、输入输出、副作用和失败边界。

新建能力时保留简短的实现输入：代表性用户问题、职责、必要知识与动作、交付结果、关键约束和验收场景。已有请求和材料足以说明这些内容时直接使用。

名称采用用户和领域熟悉的语言。让名称、description、实际能力与副作用相符；用户主要用自然语言发现能力时，描述覆盖独立的任务分支。

## 结构与资源所有权

```text
skill-name/
├── SKILL.md
├── agents/       # 产品展示、选用策略或评估角色
├── references/   # 按需读取的方法与知识
├── scripts/      # 自带的确定性工具和必要依赖
└── assets/       # 模板与素材
```

只创建当前需要的目录。按职责决定资源归属：

- Skill 的说明、辅助工具、模板和评测资源随包维护，内部路径相对于自身目录解析。
- 项目业务代码、构建脚本、规则和任务材料保持原有所有权，通过明确的项目、输入与输出路径使用。
- 独立服务和外部知识保留权威来源，声明必要依赖和读取方式。

个人跨项目能力、项目专用能力和平台内置能力按目标环境的发现机制放置。安装位置决定服务范围，资源归属由职责决定。

自带脚本定义输入、输出、副作用和失败方式；必要依赖及锁文件随脚本维护。敏感值保留在现有安全存储中，Skill 记录取得它们的方法。业务判断由 AI 结合证据完成，确定性工具返回任务需要的事实或结果。

迁移或合并时同时核对引用、调用、平台入口和旧副本的退出方式。平行候选阶段保留两边的边界，采用后再完成已确认的替换。

## 创建或更新

新建时可以复用初始化工具：

```bash
python3 <writing-for-ai>/scripts/init_skill.py <skill-name> \
  --path <target-directory> --resources references
```

初始化后按实际任务编写正文，去掉模板占位内容和无用目录。更新时先读完整上下文，保留有效能力；大幅改写需要比较行为时先保存原版完整快照。

## 名称与描述

```yaml
---
name: skill-name
description: 说明能力，以及哪些任务和场景应当选用它。
---
```

- 名称使用小写字母、数字和连字符，与目录名一致，长度不超过 64。
- description 帮助决定是否选用：表达任务、对象和必要边界，覆盖会导致不同选择的分支。
- 每句话都应影响选用判断；正文承载步骤、工具用法和输出安排。
- 任务以某个工具、产品或格式为对象时，保留准确名称以支持识别。
- `compatibility` 按需要声明运行环境；具体产品的展示和调用策略放在对应 metadata 中。

同时检查自然请求能否找到它、相邻任务是否会误选。独立入口需要独立有用的任务职责；共有参考知识也可以由普通文件和明确指针承载。

## 产品 metadata

需要 Codex 展示和调用设置时，读取 [字段说明](openai_yaml.md)，使用自带生成器：

```bash
python3 <writing-for-ai>/scripts/generate_openai_yaml.py <skill-directory> \
  --interface 'display_name=展示名称' \
  --interface 'short_description=简短说明能力和用途' \
  --interface 'default_prompt=请使用 $skill-name 完成这项任务。'
```

本个人体系以自然语言自动发现为默认，并保留按名字调用的方式。用户明确要求手动调用时，按目标产品的设置配置，并检查实际发现行为。产品 metadata 承载对应平台信息，`SKILL.md` 承载能力的行为契约。

## 验证与可选分发

新增包或改变结构后运行：

```bash
python3 <writing-for-ai>/scripts/quick_validate.py <skill-directory>
```

结构检查证明格式；脚本使用现有测试或代表性调用验证。涉及行为变化时按主流程选择真实任务检查；需要新 Codex 上下文时使用 [运行工具](codex-evaluation.md)。

需要基线比较、重复试验、人工结果审阅或触发优化时，读取 [高级评估](advanced-evaluation.md)。其中包含现有评分角色、汇总工具和 Viewer；按目标选择必要部分。Claude 专用运行工具依赖其实际 CLI，平台差异保留在结果说明中。

用户需要可安装包时再执行：

```bash
python3 <writing-for-ai>/scripts/package_skill.py <skill-directory>
```

本机或仓库直接发现即可使用时，交付对应目录。明确报告候选文件、安装、启用、替换和分发各自完成到哪一步。
