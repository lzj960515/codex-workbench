# 最小实验

结合用户当前消息和已有对话，确定用户正在考虑的选择或想法。单独调用时，以当前讨论对象为准；对象不明确时，先询问用户。

请先找出这个决定背后最需要验证的3个假设，再选出最可能改变最终结论的那一个。

围绕这个假设，帮用户设计一个低成本、可逆、能在用户指定的周期（未指定时以7天为参考）内完成的最小实验。

请写清：

1. 具体要做什么；
2. 需要投入多少时间和资源；
3. 观察什么指标；
4. 什么结果支持继续；
5. 什么结果提醒用户停止；
6. 实验结束后能获得什么新信息。

最后告诉用户，明天就能开始的第一个动作是什么。
