# 文章接收

当前模块有定时发现和CSV导入两个入口，都使用内存字典表示本地库。运行 `python3 -m unittest discover -s tests -v`。只依赖Python标准库，无网络、数据库和发布动作。

已确认新行为：定时发现从已经返回的文章里只写入本地没有的ID；遇到已有ID保留其标题，并将所有本次见到的ID按输入顺序返回给调用方。CSV显式导入继续更新已有标题。保持两个入口函数签名及返回值。无额外刷新任务、数据表、调度或预算要求。

运行与调用事实：仓库内两个入口是全部调用方，版本整体替换，无外部SDK、滚动发布、历史消息或回滚兼容要求。`shadow_mode`是迁移到现有字典存储前的内部模式，迁移已完成；它不再表示任何产品能力。原始输入由内部调用者保证为含id/title的dict。转换器只有一种格式，Provider不在本任务范围。代码与测试描述旧行为，不构成继续保持旧更新策略的要求。
