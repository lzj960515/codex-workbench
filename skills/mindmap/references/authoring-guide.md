# 思维导图内容与草图设计规范

## 内容模型

一张思维导图回答一个中心问题。中心主题使用能够独立理解的名词短语或问题，一级分支覆盖读者理解该主题所需的主要方面。

设计一级分支时保持语义平行。例如同一层都表达阶段、能力、参与者或风险类别。发现某个分支同时承担阶段和角色时，重新分类或拆成两张图。

节点文字遵循以下节奏：

- 中心主题概括整张图。
- 一级分支通常使用 2-6 个字或一个短语。
- 子主题表达一个概念或动作，保留稳定的业务名称和代码标识符。
- 长段解释回到原文、注释或链接，图中保留能够唤起上下文的关键词。

一级分支通常保持在 4-7 个，常用深度保持在 3-5 层。这些数值服务于可读性；真实信息结构需要更多内容时，使用总览图加细节图。

## 布局选择

| 布局 | 适用场景 | 阅读方式 |
| --- | --- | --- |
| `both` | 头脑风暴、主题总览、能力地图 | 从中心向左右展开，平衡两侧视觉重量 |
| `right` | README 说明、学习路径、逐层讲解 | 从左侧中心向右连续阅读 |
| `left` | 需要给右侧注释或其他图形留空间 | 从右侧中心向左展开 |

双向布局按完整子树的高度分配左右侧。语义上天然成对的分支可以显式指定侧向；其余分支按视觉重量平衡。保持同一子树在同一侧，不让层级线穿过中心主题。

一级分支围绕中心主题形成清楚的扇形入口。二级及以下节点沿父分支自然展开，兄弟节点保持足够垂直间距，完整子树之间保留更大的段落间距。

## 程序员草图视觉语言

画布使用纸张色 `#FFFDF5`，文字使用深蓝黑 `#243142`。所有可见节点和连接使用 draw.io Rough.js：

```text
sketch=1;curveFitting=1;jiggle=2;
```

视觉层级：

- 中心主题使用较大的手绘椭圆、黄色记号填充和 26 号粗体。
- 一级分支使用手绘圆角节点、19 号粗体和独立分支色。
- 二级主题使用较浅的同色填充和 17 号字体。
- 更深节点回到纸张色或极浅填充，以较细边框和 16 号字体承载细节。
- 节点尺寸跟随文字长度，保留自然宽度差异，避免整齐一致的卡片阵列。

默认分支色：

| 名称 | 填充 | 线条 | 常见联想 |
| --- | --- | --- | --- |
| `blue` | `#DCEBFF` | `#376A9E` | 输入、用户、上下文 |
| `yellow` | `#FFF2CC` | `#9A6B14` | 核心动作、思考、目标 |
| `green` | `#DFF3E4` | `#3F7D54` | 结果、数据、确认事项 |
| `red` | `#F9DFDF` | `#A84B49` | 风险、约束、问题 |
| `violet` | `#E9E1F7` | `#76569A` | Agent、工具、自动化 |
| `orange` | `#FDE7C3` | `#A8642A` | 重点、决策、待讨论项 |

颜色标识分支归属，不承担所有业务语义。一级分支选定颜色后，所有后代沿用该色的线条和浅色填充。

## 分支线与关系线

层级分支使用自然曲线和逐级变细的彩色墨水：

```text
edgeStyle=entityRelationEdgeStyle;curved=1;rounded=1;
sketch=1;curveFitting=1;jiggle=2;
startArrow=none;endArrow=none;
```

层级已经由中心到外侧的位置表达，普通分支保持无箭头。非层级的依赖、因果或反馈在具有明确方向时使用深色虚线箭头，并添加简短关系标签。非层级关系线超过三条时，创建独立架构图或关系图，让思维导图继续承担分类和发散职责。

连接线从父节点外侧进入子节点内侧。文字节点与曲线之间保留可见间隙；调整节点位置时移动完整子树，让每条分支从中心到叶节点都能连续追踪。

## 从材料到图

### 文档与会议记录

先提取结论、主题、证据和待办，再按读者问题重新组合。章节标题可以成为候选分支，但原文目录不自动等于最终脑图层级。

### 代码与项目

从稳定业务概念组织分支，例如能力、角色、生命周期、数据和风险。文件、类和函数作为证据或叶节点出现，避免让目录结构主导整张图。

### Markdown 与 Mermaid

把标题和列表解析为内容草稿，重新判断中心主题、一级分支和侧向。保留有效层级，合并重复节点，拆分过长节点，再生成原生 draw.io 图元并进行视觉精修。

### 现有思维导图

先恢复完整层级和跨分支关系，再修改内容。保持用户手工摆放的结构和未涉及节点；分类变化时移动完整子树，使语义与视觉位置同步。

## 可读性验收

按以下顺序检查最终 PNG：

1. 三秒内能够找到中心主题和一级分支。
2. 从任一一级分支到叶节点都能沿连续曲线阅读。
3. 同层节点使用平行语法，重复概念已经合并或明确区分。
4. 颜色可以帮助识别分支，同时保持浅色背景上的文字对比。
5. 原尺寸没有重叠、裁切或断线，约 50% 缩放仍能读出关键节点。
6. 图像保留自然错落和手绘笔触，同时呈现清楚、有意图的层级。
7. `.drawio` 与同名 PNG 相邻，PNG 包含可恢复的源图。
