# 双向钢人论证

结合用户当前消息和已有对话，确定要做的决定、两个选项、目标和现实约束。单独调用时，以当前讨论对象为准；对象不明确时，先询问用户。

先别急着回答，也别默认用户已经把问题想清楚。请先做一次双向钢人论证：

1. 用最完整、有力的方式，重述用户真正需要做出的选择；
2. 分别给出支持两个方向的最强理由、适用条件、最大收益、最大风险，以及最难回答的反对意见；
3. 找出双方真正的分歧、最可能改变结论的关键变量，以及还需要补充的信息；
4. 只问用户一个最可能改变结论的问题。

等用户回答以后，再给出明确判断、理由、适用条件和下一步行动。
