# 写作 Skill 按内容的读者命名

原名称 `plain-writing` 主要表达行文风格，这份 Skill 实际覆盖读者、事实、结构和交付。用户因此选择 `writing-for-humans`，与 `writing-for-ai` 对应，让名称直接说明内容写给谁。

本次将目录改为 `skills/writing-for-humans/`，Skill 名称、展示名“面向人的写作”、默认提示词和案例归属一起调整，写作方法与原有案例内容保持。README 和历史记录中的当前文档链接同步指向新目录。

本机入口与安装器通过现有托管链接迁移机制切换到新名称，其他来源的同名内容沿用既有保护方式。
