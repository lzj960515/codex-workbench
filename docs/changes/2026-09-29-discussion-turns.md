# 深度讨论明确每轮的参与方式

用户反馈：Agent 在讨论中给出分析方向和研究清单后，没有说明当前要共同决定什么，也没有区分需要用户回答的问题与 Agent 应自主查证的事实，导致对方不知道如何接话。

本次将这一行为融入 `deep-discussion` 的主体流程、证据调查、对话推进和交付说明：用户经验与取舍用具体问题展开，现有材料由 Agent 自主核实，信息充分时直接交付结论。问题的数量和形式根据实际未决事项决定。决策树参考同步采用自然对话，不再指定统一的问卷排版和逐题推荐答案。描述与 UI 提示同步表达讨论能力。

验证包括格式检查、新增的脱敏讨论案例 5，以及已有的资料充分案例 4。候选在案例 5 中给出具体的体验选择，在案例 4 中读取确认资料并直接给出结论；两次均无文件变更。旧版案例 5 同样提出了具体场景问题，本次单次对照仅支持观察到的表达差别，不证明所有场景稳定改善。独立审查批准。

个人采访 Skill 的重构仍处于讨论阶段，不属于本次修改。
