# 通用写作方法集中到 plain-writing

使用 `plain-writing` 时，正向表达要求还要回到个人规则查阅，部分例子又依赖特定业务背景。用户希望它成为可以独立使用的通用写作 Skill，并将同一类知识集中维护。

本次按读者与用途、事实与判断、信息组织、正向句式、具体用词和交付检查重整[把话说清楚](../../skills/writing-for-humans/SKILL.md)，同时承接个人规则中的例子与术语安排、中文行文和技术标识符处理方法。正文随读者语言使用，个人 [AGENTS.md](../../AGENTS.md) 保留中文交流偏好，具体写作知识由 Skill 完整提供。

正向表达覆盖全文，原有三个案例继续保护事实准确、证据状态与简洁交付。格式、链接、迁移范围检查和独立内容审阅已通过；新上下文只读取本 Skill，完成三个原案例与一条普通通知，关键事实、处理状态和用途均符合输入。这次执行证明了对应材料的独立使用，持续效果通过后续任务积累证据。
