# 批量导入接入讨论
发起人：林遥，我方后端负责人；对方：陈澄，供应商API技术负责人，负责接入支持，熟悉内部限流和幂等策略。此次文档给陈澄在下次接入会谈中回答。
目标：判断现有接口能否支持我方批量导入，并确定遇到请求超时后是否可以安全重试。预计平时8次请求/秒，高峰持续2分钟达到20次/秒；只评估已有接口，不新增供应商能力。
已经确定每批最多500条和Bearer认证。缺少：限流按什么维度及具体额度；超时后请求可能已成功时，使用相同幂等键是否避免重复创建；幂等键保证覆盖多久。公开指南没有这些答案，我方也无法从当前材料验证；陈澄掌握这些事实。
